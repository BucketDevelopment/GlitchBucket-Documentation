## Mô tả
Lệnh này hiển thị một số thông tin của bot

## Tham chiếu lệnh (Parameters)
_Bắt buộc_:
 - `command`: Chọn một lệnh bạn cần trợ giúp

import { Code } from '@astrojs/starlight/components';
