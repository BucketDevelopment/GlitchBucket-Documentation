## `/tasks autolock create` - Create a daily auto-lock task for a specific channel
Create a daily auto-lock task for a specific channel

<h4>Tham chiếu lệnh (Parameters)</h4>
_Bắt buộc:_
- `task_name`: Specify task name
- `channel`: Chọn kênh
- `timezone`: Select timezone for this server
- `lock_at`: When the channel should locked down, specify by hh:mm format.
- `unlock_at`: When the channel should unlock, specify by hh:mm format.

<h4>Ví dụ sử dụng lệnh</h4>

<Code code="/tasks autolock create task_name: channel: timezone: lock_at: unlock_at:" title="command" mark={highlights} />
