## `/customrole admin create` - Create & Assign a custom none-permission role to a member
Create & Assign a custom none-permission role to a member

<h4>Tham chiếu lệnh (Parameters)</h4>

_Bắt buộc:_
 - `above_role`: The new custom role will be above this role
 - `author`: Specify custom role's author
 - `name`: Specify role name
 - `max_users`: Maximum users can be assigned into this role
 - `expire_after`: Short date supported (e.g. 2mon1d2h), write '0' for pernament, '1' for until remove boost
 - `color`: Specify role color
 - `edit_name_permission`: Let role's author can chance their own role name
 - `edit_icon_permission`: Let role's author can chance their own role icon
 - `edit_color_permission`: Let role's author can chance their own role color
 - `manage_role_members_permission`: Let role's author can add/remove role members
 - `make_role_mentionable_permission`: Let role's author can make their role mentionable by another members

<h4>Ví dụ sử dụng lệnh</h4>

<Code code="/customrole admin create above_role: author: name: max_users: expire_after: color: edit_name_permission: edit_icon_permission: edit_color_permission: manage_role_members_permission: make_role_mentionable_permission:" title="command" mark={highlights} />
