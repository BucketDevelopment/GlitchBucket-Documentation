## `/network paping` - pap a network address
pap a network address

<h4>Tham chiếu lệnh (Parameters)</h4>
_Bắt buộc:_
- `address`: Specify a domain, or an IPv4
- `port`: Specify port, default TCP 22, HTTP(s) 80/443
- `count`: Total pap count, default 20
