## `/snowflake`

So sánh thời gian tạo giữa hai ID Discord, hoặc giữa `id1` với message/interaction hiện tại.

#### Tham số lệnh (Parameters)

**Bắt buộc:**
- `id1`: ID đầu tiên hoặc link message Discord.

**Không bắt buộc:**
- `id2`: ID thứ hai hoặc link message Discord.
