## Mô tả
Lệnh này giúp bạn chat với AI (Trí tuệ nhân tạo) với tin nhắn của bạn.

## Tham số lệnh (Parameters)
_Bắt buộc_:
 - `message`: Tin nhắn của bạn
## Ví dụ sử dụng lệnh

import { Code } from '@astrojs/starlight/components';
export const highlights = ['message:'];

<Code code="/ai message:bạn có thể giới thiệu về bản thân không?" title="command" mark={highlights} />
