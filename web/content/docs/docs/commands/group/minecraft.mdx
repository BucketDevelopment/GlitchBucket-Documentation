## `/minecraft server` - Hiển thị thông tin của một server Minecraft
Hiển thị thông tin của một server Minecraft

<h4>Tham số lệnh (Parameters)</h4>
_Bắt buộc:_
- `address`: Địa chỉ server, có thể bao gồm cổng (port)

_Không bắt buộc:_
- `name`: Tên cho server này
- `proxy_protocol`: Server có bật PROXY protocol hay không, mặc định là không
- `above_layer`: Lớp phía trên của nền (cho các khối trong suốt, như Kính hoặc Lá)
- `below_layer`: Lớp phía dưới của nền (dưới các khối trong suốt, mặc định là Đá End)
- `background`: Hình nền. Ép buộc blur trên 5. Bạn có thể chỉ định 1 URL image cỡ 2560x320 (16:2)
- `darken`: Giá trị làm tối cho nền, mặc định là 160
- `blur`: Làm mờ nền, mặc định là 0

<h4>Ví dụ sử dụng lệnh</h4>

Lệnh này sẽ kiểm tra server [`langdua.net`](https://langdua.net)

<Code code="/minecraft server address:langdua.net" title="command" mark={highlights} />

## `/minecraft custom-server-banner` - Banner riêng cho server
Hướng dẫn đặt một banner riêng cho server Minecraft của bạn, thay cho nền mặc định của `/minecraft server`

<h4>Tham số lệnh (Parameters)</h4>

_Không có tham số_

<h4>Ví dụ sử dụng lệnh</h4>
